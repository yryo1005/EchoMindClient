# EchoMindClient

ライフログ音声解析・QAシステム「EchoMind」のiPhoneアプリ(クライアント)である．日常の会話をiPhoneで常時録音してサーバーに送り，サーバーで文字起こし・話者の識別をした会話を閲覧したり，会話の内容について質問したりできる．サーバーは[EchoMindServer](https://github.com/yryo1005/EchoMindServer)である．

本READMEはV1(バージョン1.0，ビルド1)の機能をまとめたものである．開発の詳細(ファイル構成，プログラム間の依存関係，ビルドの方法)は[document.md](document.md)に記載している．

## 動作環境

| 項目 | 要件 |
| :--- | :--- |
| 端末 | iPhone(iPadは対象外) |
| OS | iOS 27.2以降 |
| 開発環境 | Xcode 27.2以降 |
| サーバー | EchoMindServer(処理状況の確認API `GET /api/upload/{id}/status` を持つ版) |

EchoMindServerは，アップロードされたAACの音声を`librosa`で読み込む．librosa 1.0以降はAACを読み込めないため，サーバーの環境ではlibrosaを1.0未満(`librosa<1`)にする必要がある．

## V1の機能

アプリはログイン後，質問・会話・人物・録音・設定の5つのタブで構成される．

### 質問

- 録音した会話の内容について質問すると，サーバーが回答を返す(`POST /api/chat`)．
- 回答の根拠となった会話の日時が表示され，タップするとその会話の該当する発言を強調して開く．
- 質問と回答の履歴は端末にアカウントごとに保存し，失敗した質問は再送できる．

### 会話

- サーバーで処理された会話を新しい順に一覧で表示する(20件ずつ読み込む)．
- 会話を開くと，発言ごとに話者名・時刻・本文を表示し，発言の音声を再生できる．
- 話者名をタップすると，その人物の名前を設定できる．

### 人物

- 話者として識別された人物の一覧と，人物ごとの発言数を表示する．
- 人物を選ぶと，その人物が参加した会話の一覧を表示する．
- 各行の鉛筆のボタン，左スワイプ，長押しのいずれかで人物の名前を設定できる．名前はその人物のすべての発言に反映される．

### 録音

- 「常時録音」をオンにすると，バックグラウンドや画面のロック中も録音を続ける．アプリを再起動しても設定は保持され，起動時に自動で録音を再開する．
- 録音は1時間ごとにファイルに区切って端末に保存する(16kHzモノラルのAAC，1時間あたり約15MB)．
- 電話やSiri等で中断された場合は，中断の終了後に自動で再開する．再開できない場合は通知で知らせる．
- 録音中にアプリが強制終了されても，それまでの音声は失われず，次の起動時に復元して送信の対象にする．
- 録音には常にiPhone本体のマイクを使う．AirPods等のBluetooth機器やイヤホンの接続中も録音を続け，他のアプリの音声はイヤホンから聞こえる．本体のマイクを使えない間のみ一時停止する．
- 保存した録音の一覧(期間，長さ，サイズ，送信の状況)を表示し，再生や手動での削除ができる．
- 録音が止まっている場合や送信を中止した録音がある場合は，タブにバッジを表示する．

### 録音の送信

- 自動送信: Wi-Fiに接続し，かつ充電中の場合に，録音を自動で送信する．条件は設定で個別に外せる(モバイル通信での送信，充電していない時の送信)．
- 「今すぐ送信」: 録音中のファイルを区切り，条件に関わらずすべての録音を送信する．
- 録音は古い順に1件ずつ送信し，サーバーでの処理が完了した時点で端末から削除する．
- サーバーでの処理に失敗した場合は，間隔を空けて最大5回まで再送する．それでも失敗した録音は端末に残し，「今すぐ送信」で再開できる．
- サーバーの停止や通信の切断の場合は，失敗の回数に数えずに時間を置いて再試行する．

### 設定

- 状態の一覧: 録音の状態，未送信の録音の件数と容量，最後に送信が完了した時刻，送信の状況，端末の空き容量を表示する．
- 常時録音のオン・オフと，自動送信の条件(Wi-Fi接続時のみ，充電中のみ)を設定できる．
- アカウントの表示とログアウトができる．未送信の録音があるか常時録音がオンの場合は，アカウント間で録音が混ざらないよう，ログアウトの前に警告する．警告では「録音を停止してすべて送信」または「録音を削除してログアウト」を選べる．
- サーバーURLの入力と接続の確認ができる(ログイン前も設定できる)．
- アプリのバージョンを表示する．

### 録音と送信のログ

- 設定の「録音と送信のログ」で，録音の開始・停止・中断，録音ファイルの区切り(区間，サイズ，バッテリー残量)，送信の結果，Wi-Fi・充電の変化等の記録を確認できる．
- 期間(24時間，3日，7日)ごとに，録音時間，録音の空白(5秒を超える隙間)とその間に起きた出来事，バッテリー残量の推移を集計して表示する．
- ログは14日間保存し，ファイルとして書き出せる．

## 使い始めるまでの手順

1. EchoMindServerを起動する．同じLAN内のiPhoneから接続する場合は，`--host 0.0.0.0`を付けて起動する．
2. `EchoMindClient.xcodeproj`をXcodeで開き，実行先にiPhoneを選んで実行する．初めて実機で実行する場合の準備(デベロッパモード，署名，開発元の信頼)は[document.md](document.md)の「開発環境のセットアップ」を参照する．
3. ログイン画面右上の歯車ボタンからサーバーURL(例: `http://192.168.0.10:8000`)を入力し，「接続を確認」を押す．ローカルネットワークへのアクセスの許可を求められたら許可する．
4. アカウントを登録(パスワードは8文字以上)またはログインする．
5. 録音タブで「常時録音」をオンにし，マイクと通知を許可する．

## データの保存場所

| データ | 保存場所 |
| :--- | :--- |
| ログインのトークン | Keychain(端末から出ない設定) |
| サーバーURL，ユーザー情報，録音・送信の設定 | UserDefaults |
| 質問の履歴，録音ファイルの記録 | SwiftData(端末内のデータベース) |
| 録音ファイル | `Application Support/Recordings`(iCloudバックアップの対象外，送信して処理が完了すると削除) |
| 録音と送信のログ | `Application Support/Logs/events.jsonl`(14日間保存) |

アプリにAPIキーは含まれない．

## V1の制約と既知の課題

- 文字起こしの精度と，音声の会話・発言への分割の精度は，サーバー側の処理に依存する．
- 録音は音量を正規化していないため，再生すると声が小さく聞こえる場合がある．
- 本体のマイクを使えない間(外部のマイクに入力が切り替わった場合等)は録音しない．
- ログインの期限切れ(7日)による自動でのログアウトでは警告を表示できないため，未送信の録音が端末に残る．次に別のアカウントでログインすると，そのアカウントに送信される．
- 同じ人物が別の人物として識別された場合に，人物を統合する機能はない．
- 端末の空き容量が少なくなった場合の通知はない．
- 一晩以上の長時間の連続稼働の検証(Step 7)は未実施である．
